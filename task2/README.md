# Лабораторная работа №2 — адаптивная вёрстка

Одностраничное портфолио Minigun Marvin. Чистые HTML и CSS, без JavaScript и сторонних библиотек.

## Файлы

```text
task2/
  index.html
  style.css
  img/
  README.md
```

## Соответствие заданию

| Требование | Где реализовано |
| --- | --- |
| До 767px | Базовые стили: одна колонка, мобильное меню |
| 768–1199px | `@media (min-width: 768px)`: двухколоночные разделы, обычная навигация |
| От 1200px | `@media (min-width: 1200px)`: три карточки портфолио, расширенные отступы |
| Mobile First | Только два медиазапроса `min-width`, без `max-width` |
| CSS Grid | `main`, шапка, герой, коллаж, заголовки разделов, основные блоки, карточки, форма и подвал |
| Свойства Grid | `grid-template-columns`, `grid-template-rows`, `gap`, `grid-column`, `grid-row` |
| Flexbox | Меню, кнопки, категории, списки, подписи фотографий, поля формы |
| Гамбургер | Три `span` внутри `summary`; мобильное меню на нативном `details` |
| Форма | Подписанные поля «Имя», «Email», «Сообщение», кнопка «Отправить» |
| Состояния полей и кнопок | Обычное, `:hover`, `:focus`, дополнительно `:focus-visible` |
| Плавный переход | Цвет кнопок и полей, увеличение фотографии при наведении |
| Размеры элементов | Поля и кнопки от 48px, ссылки навигации от 44px |
| Без JavaScript | Нет `script` и обработчиков событий |
| Без инлайн-стилей | Всё оформление вынесено в `style.css` |
| Семантика | `header`, `nav`, `main`, `section`, `article`, `figure`, `figcaption`, `footer` |
