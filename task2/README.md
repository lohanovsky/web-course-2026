# Лабораторная работа №2 — адаптивная вёрстка

Одностраничное портфолио Minigun Marvin. Чистые HTML и CSS, без JavaScript и сторонних библиотек.

## Файлы

```text
task2/
  index.html
  style.css
  img/
  README.md
```

Для локального просмотра откройте `index.html` в браузере. Интернет для отображения страницы не требуется; внешние ссылки ведут на альбом и социальные сети.

## Соответствие заданию

| Требование | Где реализовано |
| --- | --- |
| До 767px | Базовые стили: одна колонка, мобильное меню |
| 768–1199px | `@media (min-width: 768px)`: двухколоночные разделы, обычная навигация |
| От 1200px | `@media (min-width: 1200px)`: три карточки портфолио, расширенные отступы |
| Mobile First | Только два медиазапроса `min-width`, без `max-width` |
| CSS Grid | `main`, шапка, герой, коллаж, заголовки разделов, основные блоки, карточки, форма и подвал |
| Свойства Grid | `grid-template-columns`, `grid-template-rows`, `gap`, `grid-column`, `grid-row` |
| Flexbox | Меню, кнопки, категории, списки, подписи фотографий, поля формы |
| Гамбургер | Три `span` внутри `summary`; мобильное меню на нативном `details` |
| Форма | Подписанные поля «Имя», «Email», «Сообщение», кнопка «Отправить» |
| Состояния полей и кнопок | Обычное, `:hover`, `:focus`, дополнительно `:focus-visible` |
| Плавный переход | Цвет кнопок и полей, увеличение фотографии при наведении |
| Размеры элементов | Поля и кнопки от 48px, ссылки навигации от 44px |
| Без JavaScript | Нет `script` и обработчиков событий |
| Без инлайн-стилей | Всё оформление вынесено в `style.css` |
| Семантика | `header`, `nav`, `main`, `section`, `article`, `figure`, `figcaption`, `footer` |

Форма учебная: без `action`, кнопка имеет `type="button"`, чтобы не перезагружать страницу и не отправлять личные данные. Сообщения через неё не отправляются. Ссылка на Telegram взята из исходного альбома. Меню работает встроенными средствами браузера, без JavaScript.

## GitHub Pages

1. Распакуйте архив. Поместите папку `task2` в корень репозитория курса.
2. Добавьте файлы, сделайте commit и push.
3. В `Settings → Pages` выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`.
4. Откройте `https://<логин>.github.io/<репозиторий>/task2/`.
5. Сдайте эту ссылку и ссылку на исходный макет Figma.

## Проверка перед сдачей

В DevTools включите режим устройства (`Ctrl+Shift+M`). Проверьте ширины 320, 390, 767, 768, 1199, 1200 и 1440px: отсутствие горизонтального скролла, читаемость текста, форму, мобильное меню и переходы по якорям. В консоли можно проверить `document.documentElement.scrollWidth === window.innerWidth`. Затем проверьте страницу на телефоне.

В среде подготовки браузерная проверка недоступна. Выполнена статическая проверка HTML/CSS, ссылок на локальные файлы и требований лабораторной. GitHub Pages необходимо включить в вашем репозитории; загрузка туда в этой работе не выполнялась.
