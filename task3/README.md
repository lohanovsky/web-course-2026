# Лабораторная работа 3 — Список задач

Приложение позволяет добавлять и удалять задачи, отмечать их выполнение и фильтровать список. Счётчик показывает количество оставшихся и выполненных задач во всём списке.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и запуск сервера не нужны.

## Управление

- Введите задачу и нажмите «Добавить» или Enter. Пустой текст и строка из пробелов не принимаются.
- Установите флажок рядом с задачей, чтобы отметить её выполненной; снимите его, чтобы вернуть задачу в активные.
- Нажмите «Удалить», чтобы убрать задачу.
- Используйте кнопки «Все», «Активные» и «Завершённые» для выбора отображаемых задач.

Задачи хранятся только в памяти страницы: после перезагрузки список очищается.

## Файлы и логика

- `index.html` — поле ввода, кнопки, список и счётчик.
- `style.css` — оформление страницы, выделение выбранного фильтра и зачёркивание выполненных задач.
- `script.js` — массив `tasks` с полями `id`, `text`, `completed`; функции добавления, переключения статуса и удаления. `getVisibleTasks()` отбирает задачи по фильтру, а `render()` заново строит список и обновляет счётчик после изменений.
