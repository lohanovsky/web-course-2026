# Лабораторная работа 5 — Simon

Игра на память: приложение подсвечивает последовательность цветных кнопок, а игрок повторяет её. На каждом уровне к последовательности добавляется один случайный цвет.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сервер не нужны.

## Управление

1. Нажмите «Старт» и запомните порядок подсветки кнопок.
2. Когда появится «Ваш ход», нажимайте цветные кнопки в том же порядке.
3. После правильного ответа следующий уровень начнётся автоматически. Во время показа последовательности нажатия не учитываются.
4. Ошибка завершает игру: выводится достигнутый уровень. Нажмите «Старт», чтобы начать заново.

## Файлы и логика

- `index.html` — игровое поле из четырёх кнопок, уровень, сообщение и кнопка запуска.
- `style.css` — тёмная тема, сетка 2 × 2 и подсветка кнопок через класс `active`.
- `script.js` — состояние игры в объекте `state`, генерация последовательности, её показ и проверка нажатий. `nextRound()` добавляет случайный цвет, `showSequence()` показывает последовательность с паузами, а `handlePadClick()` сравнивает ответ с очередным элементом.
